= ACP

== NAME

acp -- acp is an AI tool for installing an ACP Agent and interact with it: OpenCode, Claude, Pi, Gemini, IBM Bob, etc.

== SYNOPSIS

[source]
----
acp [-h] [COMMAND]
----

== OPTIONS

*-h*, *--help*::
Display this help and exit

== COMMANDS

* link:acp-run.adoc[*run*] - Run a headless (non-interactive) conversation with an ACP agent
* link:acp-registry.adoc[*registry*] - Manage ACP agents via the registry: list, install, remove
* link:acp-model.adoc[*model*] - Manage model: list


= ACP-RUN

== NAME

acp run -- Run a headless (non-interactive) conversation with an ACP agent

== SYNOPSIS

[source]
----
acp run [-hv] [-a=<agent>] [--agent-binary=<agent-binary>] [--agent-args=<agent-args>] -p=<prompt> [--provider=<provider>] [-m=<model>] [--request-timeout=<request-timeout>] [--prompt-request-timeout=<prompt-request-timeout>] [--permission-mode=<permission-mode>] [-s=<skill-path>] [-b=<backup>] [--backup-project-name=<backup-project-name>] [--workspace-path=<workspace-path>] [-o=<output>] [-l=<log-level>]
----

== OPTIONS

*-h*, *--help*::
Display this help and exit

*-a*, *--agent*=<agent>::
ACP agent registry ID: opencode, claude-acp, pi-acp, gemini, ... (use 'acp registry list --remote' to see the available acp agents) [env: ACP_AGENT]
+
Default: `claude-acp`

*--agent-binary*=<agent-binary>::
Override agent binary path (for custom agents) [env: ACP_AGENT_BINARY]

*--agent-args*=<agent-args>::
Override agent arguments (for custom agents) [env: ACP_AGENT_ARGS]

*-p*, *--prompt*=<prompt>::
The prompt text to send to the agent [env: ACP_PROMPT]

*--provider*=<provider>::
Provider: zen, vertex-ai [env: ACP_PROVIDER]

*-m*, *--model*=<model>::
The model to use, e.g. claude-opus-4-6 (resolved per agent/provider) [env: ACP_MODEL]

*--request-timeout*=<request-timeout>::
Timeout in seconds for requests (initialize, create session, etc.) [env: ACP_REQUEST_TIMEOUT]

*--prompt-request-timeout*=<prompt-request-timeout>::
Timeout in seconds for prompt request; 0 means no timeout [env: ACP_PROMPT_REQUEST_TIMEOUT]

*--permission-mode*=<permission-mode>::
How to respond to agent permission requests: allow_always, allow_once, reject_once, reject_always [env: ACP_PERMISSION_MODE]
+
Default: `allow_always`

*-s*, *--skill-path*=<skill-path>::
Absolute path to a skills folder to add as additional directory [env: SKILL_PATH]

*-b*, *--backup*=<backup>::
Backup workspace to target/workdirs before running: yes, no (default: yes). Only applies to Maven/Gradle projects [env: ACP_BACKUP]

*--backup-project-name*=<backup-project-name>::
Name of the project used in the backup directory: target/workdirs/<name>_<timestamp> (default: current directory name) [env: ACP_BACKUP_PROJECT_NAME]

*--workspace-path*=<workspace-path>::
Absolute path to the project/workspace directory used as CWD for the session. If not set, defaults to the directory where the command is executed [env: WORKSPACE_PATH]
+
Aliases: `--wks`

*-o*, *--output*=<output>::
Output mode: default (human-friendly), json (raw JSON-RPC messages) [env: ACP_OUTPUT]

*-v*, *--verbose*::
Enable to log JSON RPC messages [env: ACP_VERBOSE]

*-l*, *--log-level*=<log-level>::
Log level: INFO, DEBUG, TRACE, WARNING, SEVERE [env: ACP_LOG_LEVEL]


= ACP-REGISTRY

== NAME

acp registry -- Manage ACP agents via the registry: list, install, remove

== SYNOPSIS

[source]
----
acp registry [COMMAND]
----

== COMMANDS

* link:acp-registry-list.adoc[*list*] - List ACP agents (installed or from the registry)
* link:acp-registry-install.adoc[*install*] - Install an ACP agent from the registry
* link:acp-registry-remove.adoc[*remove*] - Remove an installed ACP agent


= ACP-REGISTRY-LIST

== NAME

acp registry list -- List ACP agents (installed or from the registry)

== SYNOPSIS

[source]
----
acp registry list [-r]
----

== OPTIONS

*-r*, *--registry*::
List all agents from the remote ACP registry instead of the locally installed


= ACP-REGISTRY-INSTALL

== NAME

acp registry install -- Install an ACP agent from the registry

== SYNOPSIS

[source]
----
acp registry install [-f] <agentId>
----

== OPTIONS

*-f*, *--force*::
Force reinstall even if the agent is already installed

== ARGUMENTS

*<agentId>*::
Agent identifier from the ACP registry (e.g. opencode, claude-acp, gemini)


= ACP-REGISTRY-REMOVE

== NAME

acp registry remove -- Remove an installed ACP agent

== SYNOPSIS

[source]
----
acp registry remove <agentId>
----

== ARGUMENTS

*<agentId>*::
Agent ID to remove (e.g. opencode, claude-acp)

= ACP-MODEL-LIST

== NAME

acp model list -- Display the models available for an agent to interact with the LLM model

== SYNOPSIS

[source]
----
acp model list -a=<agent>
----

== OPTIONS

*-a*, *--agent*=<agent>::
Acp agent name to query to get the models. Use the commands: acp registry list to get the id/name !
