= ACP-REGISTRY

== NAME

acp registry -- Manage ACP agents via a local registry: list, install, remove

== SYNOPSIS

[source]
----
acp registry [-h] [COMMAND]
----

== OPTIONS

*-h*, *--help*::
Display this help and exit

== COMMANDS

* link:acp-registry-list.adoc[*list*] - List ACP agents: installed or from the remote acp registry.
* link:acp-registry-install.adoc[*install*] - Install an ACP agent from the registry
* link:acp-registry-remove.adoc[*remove*] - Remove an installed ACP agent
